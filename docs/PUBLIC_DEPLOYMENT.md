# 在线体验版与发布

本轮更新：2026年10月23日。

公开访问入口：https://ethen-chuan.github.io/evalpilot-support/

## 两种运行方式

| 能力 | GitHub Pages 公开体验 | 本机完整版 |
| --- | --- | --- |
| 同例答复对照 | 三个人工编写场景，不是模型成绩 | 用户授权后的真实模型答复 |
| 标签诊断 | 说明标签含义，不计算模型分数 | 来源标签与实际输出核对 |
| 对话测试树 | 编辑、路径预览、本浏览器保存 | 同样支持设计，尚无多轮执行器 |
| 数据导入、模型连接、裁判评测 | 不提供，不收集 API Key | 配置扫描器、脱敏数据与外发授权后使用 |
| Trace、运行历史、质检和 DSAT | 不上传、不展示本机数据 | 来自本机实际记录，不补造缺失指标 |

浏览器草稿只存于当前域名的本地存储，需明确勾选匿名内容确认；不上传、不跨设备同步。请勿输入客户信息、凭证或内部资料。异常草稿不会被自动覆盖。页面使用 `connect-src 'none'` 的 CSP 禁止模型、遥测和后端 API 请求，无第三方脚本、字体、分析器。

## 更新页面

```sh
npm ci
npm run build
npm run prepare:pages
node --test tests/*.test.ts
```

独立入口是 `site/index.html` 与 `src/publicMain.tsx`，不把完整版入口伪装成可用的云端服务。构建先输出到被 Git 忽略的 `work/public-site-build/`，再只复制三个公开产物到 `docs/index.html`、`docs/assets/public.js` 和 `docs/assets/index.css`，并写入 `.nojekyll`。不会复制本机数据、后端配置或完整产品的 `dist/`。

预览：`python3 -m http.server 4296 --bind 127.0.0.1 --directory work/public-site-build`。检查 `#cases`、`#tree`、`#guide`，桌面和手机布局、明暗主题、浏览器草稿以及网络请求。

发布前逐一检查所有提交文件及编译产物，完成脱敏扫描和人工复核。源码和产物必须一起提交；不能只修改源码却继续发布旧页面。GitHub 仓库 Settings → Pages 选择从分支部署，分支 `main`、目录 `/docs`。等待部署完成后验证实际网页及两个资源地址，不把预期域名当作已成功发布。

可选交互回归测试需要仓库外提供 `jsdom` 依赖目录：

```sh
JSDOM_PACKAGE_ROOT=/absolute/path/to/jsdom-project node tests/public_site_dom.cjs
```

该测试禁止所有 API 请求，覆盖场景切换、观察点重置、未评审状态、明暗主题、离线对话树、草稿保存/恢复/损坏与安装说明。客户端输入检测只是一层保护，不能保证绝对安全。

## 完整云端服务尚未部署

当前后端是单用户本机工具，不具备公网多用户安全能力。完整云端版至少需要托管后端与数据库、登录和访问控制、每用户数据隔离、服务端密钥托管、可用的隐私扫描/OCR、限流与调用预算、审计和备份。需选定部署账号与资源并完成安全验收后另行上线。不要暴露本机端口，也不要把客户数据库放进 Pages 或 GitHub。

本轮本机回归：56项 TypeScript 单元测试通过；226项 Python 测试中225项通过，保留已知固定日期排序用例失败，不将其描述为全量通过。对话树、答复复核与公开入口使用隔离构造数据进行交互测试，不调用付费模型，不产生真实业务成绩。
