- 不包含原始或脱敏客户对话、质检表、客户图片、数据库、运行日志、API 凭证、个人数据仓库登记、模型文件或完整恢复点。
- 文档中的私人导入批次、记录数量及源数据指纹已移除。公开示例、测试夹具和设计指标不是真实客户数据或经营业绩。

- 全部文本按完整字节扫描；扫描器不直接识别的脚本后缀使用等字节 UTF-8 文本副本补扫并核对指纹，不截取摘要。
- 自动规则对代码取值表达式、防泄露提示、检测规则、测试地址及比例计算有命中，人工核对其上下文。没有为了消除关键词命中而删除防泄露规则；不宣称整库自动扫描零命中或绝对安全。

## 使用方式

按照 README 准备依赖、构建并在本机运行。首次运行没有作者的私有数据、评测历史或模型连接；需要使用者自行准备获授权的脱敏数据和模型权限。

原 GitHub Pages 页面仍为明确标注的静态交互体验，不是完整后端，也不接收 API Key。完整本地功能不会因为推送源码而自动变成公网服务。不得将未鉴权的本机后端直接暴露到公网。
