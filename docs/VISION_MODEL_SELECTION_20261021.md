# 图文模型选择修复与验收

日期：2026-10-21。范围：图文模型对比的模型选择与连接验证窗口。

## 原因

旧列表只展示内存中已配置且 `visionTested=true` 的模型。工作区已接入的两个模型只有文字测试通过，因此被隐藏；用户只能看到占位文本，无法选中并诊断连接。未通过看图测试不等于模型本身一定不支持图片。

## 修复

- 展示全部已注册外部模型，可选择未验证模型，在选项和下方显示连接状态及「验证看图」「输入 Key」「管理连接」。不自动选择本地分类器。
- 页面明确说明图文评测与文字对比的差别，提供「文字客服对比」入口并保留显式项目参数。
- 连接窗口区分文字与看图测试状态；从图文入口打开时，文字通过不能解锁「完成并选用此模型」。测试失败或响应缺少看图通过标记也不能解锁。
- 配置仍在内存时不要求重复输入 Key。已验证连接可带回原选择位置；新建连接验证通过后也可直接选用。
- 候选和可选裁判均须通过看图测试才可运行。两个连接指向同一厂商同一模型 ID 时禁止对比；改基线造成重复时清空候选并要求重选。
- 配置过期、看图验证状态变化、读取失败均阻止运行，并撤销外发确认。选择与轮询不调用模型。
