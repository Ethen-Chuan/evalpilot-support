# RCA、Trace、训练实验与图库迭代 · 公开版

功能日期：2026年10月14日；公开版整理：2026年10月16日。内部数据规模、成绩与实验编号已从本发布副本去除，原工作区保留。

## 交付内容

- DSAT：真实低分评价与投诉/复核线索分开，完整文字证据、六类排查、草稿、人工归因、修复、回归验收和版本历史。
- Trace：按业务分类、来源、批次、状态与耗时组合筛选，说明本次计时范围；历史对话没有的操作不补造。
- 训练：按25%/60%/100%固定嵌套训练子集重新拟合，同一独立测试集评测，保留改善和回退；重复条件可能得到相同结果，不加随机分数。
- 图文：24张已审核公开图片，含20张VisA板卡照片与4张局部图，带来源署名、完整性指纹、场景筛选、分页预览与按数重跑。题目为平台改编，不代表客户工单或完整VisA基准。
- 实验管理：项目内名称/备注搜索、收藏、软归档、恢复、全历史分页、版本冲突、批量原子性和运行中限制。元数据独立保存，不覆盖成绩、原对话或Trace。
- 无生产结果时显示接入说明，不用离线成绩补线上KPI。

## 验证

后端回归覆盖归因项目隔离、草稿与证据门槛、训练子集、Trace分类及图片指纹；隔离交互覆盖训练、记录管理、复核、裁判替身、RCA和图库。当前构建及测试结果见RELEASE_CHECKS.md。

没有真实供应商推理成绩，也未完成原生浏览器像素级布局验收。调用外部模型需用户提供Key、通过连接测试并授权本次范围和费用。
