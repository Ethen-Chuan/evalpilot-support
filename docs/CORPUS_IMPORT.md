# 授权文本语料脱敏与导入

仓库不附带原始数据或任何客户的脱敏副本。以下工具面向本机受控处理，不会自动下载私人附件，也不把数据推送到 GitHub。

## 前提

使用者确认数据权利与处理用途，保留原件，在单独的本机目录生成脱敏副本。批量转换依赖兼容的原生 DLP Python 模块和 CLI；具体接口见 SECURITY.md，模块与组织策略不随仓库发布。

## 流程

1. 使用 `scripts/redact_labeled_dataset.py --help` 查看支持的标注导出结构和输入选项。格式不匹配时停止，不跳过记录后冒充完整导入。
2. 为不同来源规划唯一 datasetId。发布版默认使用通用名称，不含原工作区客户标识；导入多项目时由维护者显式调整，不能覆盖已有来源。
3. 生成 `_redacted.jsonl` 与待复扫 manifest，保留角色、消息顺序和标注。身份、媒体链接和高风险正文隔离；不回填不存在的历史 Trace。
4. 用 `scripts/verify_labeled_dataset.py --help` 指定待复核目录，执行全量扫描及内容指纹核验，再由业务人员检查隐含身份、标签冲突和使用边界。不能手工将扫描状态改成通过。
5. 使用 `backend/corpus_import.py --directory /path/to/redacted-package --backup /path/to/local-backup.sqlite3` 导入。备份和数据包都保留本机，不能添加到源码仓库。

导入事务检查数据清单、文件哈希、消息数量、角色、顺序和唯一标识。相同数据重复导入保持幂等；同一记录内容改变会拒绝覆盖，须显式设计版本迁移。资料不会自动发布为客服知识，也不会自动训练模型。

图片和视频在此文本流程中隔离，不解封。真实图片评测使用页面的独立图文入口，先本机 OCR / DLP 检查，再人工隐私和业务标注复核。
