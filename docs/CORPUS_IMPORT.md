# 授权文本语料脱敏与导入

仓库不附带原始数据或任何客户的脱敏副本。以下工具面向本机受控处理，不会自动下载私人附件，也不把数据推送到 GitHub。

## 前提

使用者确认数据权利与处理用途，保留原件，在单独的本机目录生成脱敏副本。批量转换依赖兼容的原生 DLP Python 模块和 CLI；具体接口见 SECURITY.md，模块与组织策略不随仓库发布。

## 流程

1. 使用 `scripts/redact_labeled_dataset.py --help` 查看支持的标注导出结构和输入选项。格式不匹配时停止，不跳过记录后冒充完整导入。
2. 为不同来源规划唯一 datasetId，用 `--dataset-id` 显式指定稳定的小写项目编号。发布版默认使用通用名称，不含原工作区客户标识；不能覆盖已有来源或非空输出目录。
3. 生成 `_redacted.jsonl` 与待复扫 manifest，保留角色、消息顺序和标注。身份、媒体链接和高风险正文隔离；不回填不存在的历史 Trace。
4. 用 `scripts/verify_labeled_dataset.py --help` 指定待复核目录，执行全量扫描及内容指纹核验，再由业务人员检查隐含身份、标签冲突和使用边界。不能手工将扫描状态改成通过。
5. 使用 `backend/corpus_import.py --directory /path/to/redacted-package --backup /path/to/local-backup.sqlite3` 导入。备份和数据包都保留本机，不能添加到源码仓库。

导入事务检查数据清单、文件哈希、消息数量、角色、顺序和唯一标识。相同数据重复导入保持幂等；同一记录内容改变会拒绝覆盖，须显式设计版本迁移。资料不会自动发布为客服知识，也不会自动训练模型。

图片和视频在此文本流程中隔离，不解封。真实图片评测使用页面的独立图文入口，先本机 OCR / DLP 检查，再人工隐私和业务标注复核。

需要随应用迭代保留私有数据时，可单独建立个人私有数据仓库，并登记固定提交与清单指纹；详见 [私有项目集保存与恢复](PRIVATE_DATASETS.md)。原始附件、密钥和任何数据仍禁止进入公开源码仓库。

## 按会话范围查看数据画像

数据画像读取已提交、未取消的来源人工标签，不补写标签，也不把原始原因说明当作模型评分。

- 全部 / 常规会话：优先展示意图、情绪、产品等八个业务维度；范围标记及原始原因另行展开。
- 无效会话：优先展示 `invalid_reason`，可按原始原因或缺失原因筛选并查看完整对话。
- 直接转人工：优先展示 `handoff_reason`，不等同于人工已经接通或安全策略要求必转人工。
- 范围待确认：显示全部标签为空、缺少无效标记、缺少转人工标记的数量。缺失项可以重叠，不可相加；有其他业务标签时仍可展开查看。无法识别的范围值也保留待核对。

特殊范围不铺开零覆盖率的业务卡片，但明确显示来源缺少多少个业务字段；缺失不自动解释为“不适用”。无效 / 转人工原因是原始自由文本，只去除首尾空白并按会话去重，不自动合并同义表达。点击原因后的列表、分页、搜索及返回对话均保留同一统计口径；切换范围会清空标签和状态筛选，保留搜索文本。

接口 `facets=1` 返回 `profileVersion=2`，包含范围标记和原因维度、原始说明类型及 `unlabeledSessions`。旧后台需重启后才可使用新版画像。此更新只调整统计和展示，不改写原始会话、标注、私有数据版本或自动恢复登记。
