# 售后客服评测平台 · 操作说明

此源码版不附带客户数据、已训练模型和历史成绩。首次看到空项目与「未测」是正常状态，不代表安装失败。建议先走图文校验流程，再导入有权使用的真实案例。

## 1. 打开平台与检查环境

1. 按 README 安装依赖，构建页面并启动本机服务。
2. 确认已配置兼容的本机 DLP 扫描器；图像检查另需 macOS Vision 与编译工具。未配置时不能导入或外发资料，不要跳过门禁。
3. 打开「模型对比」，选择「图文与转人工拦截」。

[打开图文评测](http://127.0.0.1:4287/#compare?mode=vision)

## 2. 准备图片与售后问题

1. 演练可点击「使用 4 个自建校验案例」。这是程序绘制的 E04 / E09 屏幕，不是真实客户，没有预设分数。
2. 真实案例点击「添加真实图文案例」。先在原件之外制作脱敏副本，再选 PNG / JPEG，最大 4MB、600 万像素。
3. 本机 OCR 与扫描后，人工检查人脸、姓名、手机号、二维码、工牌、地址、设备编号和组织信息。自动检查不保证绝对安全。
4. 填写问题或截止当前的完整对话、政策、人工核验的视觉事实、参考答复和标准路由，确认后保存。保存本身不调用模型。

真实来源和自建校验分开评测，不混为一组；原始媒体不会自动解封或从私人链接下载。

## 3. 接入两个模型

1. 点击「添加模型 / 输入 Key」。跨厂商可分别创建 OpenAI / Anthropic 连接，同厂商版本对比则创建两个不同模型 ID 的连接。
2. 模型 ID 以账号实际可用、支持图像的版本为准，不能只修改显示名称。
3. 只在 API Key 密码框输入密钥，确认用途后保存到本机服务内存。不要把密钥写入聊天、截图或仓库。重启后需要重新输入。
4. 另行授权后点击「测试图像读取」。它会真实发送自建随机码图片，候选与不同的裁判模型最多各调用一次，可能计费。读对才可以参与图文评测。

只通过文字测试不代表能看图；保存连接不代表已经测得业务效果。

## 4. 运行同批比较

1. 填数量并点击「按数量选择」，或手动勾选，确认已选案例数。每批 1–50 例。
2. 选择两个候选、同一个独立裁判；没有裁判也可等待人工逐条复核。
3. 核对发送目的地、数据范围和最大调用次数。每例最多两次候选调用，带裁判最多四次，不自动重试。
4. 确认有权外发及可能费用后开始运行。双方收到同一图片、问题和政策；候选不收到参考答案与路由标注。

## 5. 看拦截大盘与证据

- 有效拦截率（离线评审）：标准路由可自助、模型直接答复，且看图正确、答复合规、完整解决三项均通过的案例数，除以全部选定案例。失败、未执行和待评不算成功；全部未评显示未测。
- 必须转人工却被拦截率：应当转人工却继续答复或澄清的比例，越低越好。未完成案例单列，不能把零错误当成安全通过。
- 必要转人工召回：应该升级的案例中，正确建议人工的比例。明确人工请求、安全风险和超权限时必须尊重升级。
- 未建议转人工率只是代理指标，不等于问题解决。视觉正确率和评审覆盖的分母单独显示。
- 线上真实拦截率目前未测，需要完整会话的解决确认、实际转接、观察窗口及复访；沉默和放弃不能自动当成功。

在逐例对照中查看原图、问题、两份客服回复、路由和裁判理由。点击「查看 Trace」检查实际调用与模拟动作，再返回原批次。这里只记录可观察步骤，不记录隐藏思维链，也不执行真实退款、派单和转接。

## 6. 人工复核与重跑

1. 点击「人工复核」，逐项判断并填写依据。人工意见优先于裁判，原始输出与每次修订保留。
2. 点击「选数量重跑本批」，改数量并再次点击「按数量选择」，确认授权后生成新批次，旧记录不覆盖。
3. 底部比较只接受相同案例、图片、政策、协议和裁判条件。子集不能直接和完整批次排名。
4. 共同完成且已评审的配对差异与全量分母指标分别展示。小样本或区间跨零不能认定模型更好。

## 可选：文本对话、训练与知识库

先按照数据导入说明完成授权、脱敏、复扫与导入，售后项目才会出现。进入项目后可阅读微信式完整对话；训练本地行为基线后才能选择本地版本运行文本评测。当前不是云端微调模型，也不会预置某个客户的训练成果。

知识整理、人工审核和发布答复知识是另一条流程，不会自动更新本地分类器分数。试聊、模型连接、知识库与 Trace 位于「更多工具」。

## 遇到问题时

- 页面打不开：检查服务是否运行，端口是否已占用；不要关闭不认识的程序或清空数据库。
- 项目或模型为空：源码版未附带业务数据，需要自行导入 / 训练，图文模型需要自行连接。
- 图片或文字被拒绝：检查 DLP 环境并在副本上脱敏，不伪造扫描通过状态。
- 外部调用失败：核对模型 ID、密钥权限、额度与视觉能力，失败不会补成假成绩。
- 没有可比结果：同批选择两个模型、同裁判，等待执行完成后再比。
- 图文现在只支持单轮文字 + 单张图片，不支持音频 / 视频，也不代表闭环客服业务效果。
