# 回放控件重叠修复

日期：2026-10-21。范围：结果大盘「正式对话 · 本机学习」顶部操作区。

原因为旧操作区第一列固定 95px，后来加入训练比例下拉框但没有调整列宽，标签的默认最小尺寸又允许下拉框撑出列边界，覆盖回放数量输入框。不存在重复数据或重复渲染控件。

修复仅涉及样式：训练选择与数量输入各占独立列，输入统一高度并限制在本列内；运行按钮独占下一行；介绍文字与操作区按容器可用空间换行，手机宽度下两个字段上下排列。没有修改训练参数、统计数据或模型行为。

验收：

- 构建通过，原有包体积警告未扩大处理范围。
- `tests/learning_controls_layout.cjs` 使用真实 React 组件和项目样式，在隔离数据上核对 320、390、540、768、1024、1280、1440、1920px 八种宽度及三种训练选项，另覆盖窄父容器、150% 布局缩放和运行中禁用状态。
- 断言字段、按钮、介绍文字互不覆盖；控件不溢出父容器；按钮位于两字段下方；数量校验仍生效。测试全程阻止网络，不启动训练。
- 本机真实页面补测 320、390、768、1024、1440px，均只有一个训练下拉框和一个数量输入框，无重叠或横向溢出，无脚本报错。
- 本环境命令行浏览器启动受系统沙箱限制；测试通过导出函数复用应用内已打开的浏览器完成。一般环境可设置 `PLAYWRIGHT_PACKAGE_ROOT` 后直接运行该测试。

本次没有重启后端、运行模型或改变历史记录。临时排版截图隐藏业务统计，不加入源码仓库。
