# 体验大盘验证记录 · 公开版

更新日期：2026年10月16日。本文保留功能与验收边界，不分发客户记录数量、项目标识、业务成绩或规则原文；完整内部验证记录留在原工作区。

## 已实现

- 结果大盘包含业务指标、质检复核、DSAT归因和意图树；生产、沙箱、离线回放及图文专项分开。
- 质检改判率、覆盖率和本平台人工复核完成率分别保留分子分母；未知和冲突不算通过。
- 字段及复核环形图可下钻；模型累计曲线由逐例输出计算，同条件历史不足时不生成假趋势。
- 意图树保留单一/多意图全部来源案例，显示学习资格，支持折叠、分页与完整对话。
- RCA支持六类排查、一个主因及多个促成因素、证据、反事实、修复与人工回归验收；线索不冒充生产DSAT。
- 结果接入带授权、脱敏、项目约束、幂等和冲突回滚；不连接真实CRM或执行派单。

## 验证边界

隔离测试覆盖本地学习、质检、裁判替身、环图、曲线、意图分页和RCA闭环。测试构造只写临时数据库；内部已有记录另做只读检查，不把构造成绩写入业务项目。

JSDOM固定图表容器仅证明DOM渲染和交互，不代表真实浏览器截图或响应式视觉验收。已知的历史固定日期排序失败保留，当前发布测试结果见RELEASE_CHECKS.md。

## 复跑

使用新建隔离目录启动tests/experience_browser_server.py。设置JSDOM_PACKAGE_ROOT为安装jsdom的目录、EVAL_BROWSER_BASE为隔离服务地址，再运行tests/experience_dom_check.cjs。EVAL_READONLY=1用于已有项目的只读检查。

本机DLP扫描器不可用时受保护操作拒绝执行，不提供无条件通过的扫描替身。图片、源文档及内部统计不随本验证说明发布。
