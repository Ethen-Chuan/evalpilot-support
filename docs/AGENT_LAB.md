# 本地售后行为基线与版本比较

本仓库不附带真实语料、训练产物和业务结果。导入有权使用、通过脱敏和复核的会话后，可在本机训练意图与行为分类器；它不是大模型微调。

每段会话提取一个有效人工答复回合，用其之前的完整上下文预测下一步。跳过欢迎语、无效记录、标注分歧与缺少目标的会话。人工原文推导的行为标签属于弱标签，不保证业务正确。

按匿名客户与归一化重复问题分组，隔离 train / validation / test。两个本地版本使用字符 TF-IDF 与不同分类器，答复为安全模板；相似训练案例只能作处理方向参考，不是正式维修政策。

文本评测支持同案例、多模型、裁判及重跑。意图匹配、行为匹配和联合匹配不等于真实解决率。外部候选使用已有模型接口，保存 Key 不代表发起了训练。

任何版本升级必须运行相同案例和协议；保留改善、回退、失败及未测，不只展示好看的分数。相同来源和测试条件才能进行配对比较。

图文与转人工指标独立于旧文本协议，详见 MULTIMODAL_EVALUATION.md；不能用文本占位和意图分类成绩宣称视觉能力。
