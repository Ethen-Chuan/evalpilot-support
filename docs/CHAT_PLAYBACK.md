# 完整对话的聊天式回放

“对话知识库”的正文使用左右气泡呈现：客服在左、客户在右。头像只是角色图标，不使用客户照片或伪造姓名。机器人、人工客服分别标识；系统和工具记录居中显示，不冒充客户或客服发言。

- 默认完整展开，严格按原始消息序列展示，不合并、删除或省略连续消息。
- 保留消息序号与时间。历史语料显示相对时间，不伪造绝对时间、已读回执、在线状态或上游执行轨迹。
- 原始业务标注默认折叠，点击“原始业务标注”查看完整字段、分歧及知识缺口。
- “选择知识依据”开启逐条选择；退出后清空本次选择。整理草稿仍要求同时选择客户问题与客服答复，且发布前另行审核。
- “专注阅读”隐藏两侧会话列表和分析栏，扩大聊天区域；退出后恢复。
- 搜索仅高亮原文，可以定位下一处，不隐藏不匹配的中间消息。
- “紧凑滚动”只改变阅读容器，不减少已加载的消息数量。
- 真实记录已有的 Trace、知识版本和负反馈仍挂在对应消息下方；资料版本、全文导出和数据本身不变。
- 气泡和头像跟随工作区配色，支持浅色、深色及手机布局。

实现入口：`src/ConversationPlayback.tsx`、`src/conversation-playback.css`。该改版不修改数据库、脱敏正文或原始标注。
