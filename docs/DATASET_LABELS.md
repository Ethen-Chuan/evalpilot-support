# 数据集会话分类统计

更新：2026-10-20。入口：项目集 → 选择项目 → 案例列表。

## 操作步骤

1. 案例列表搜索框上方展示八类卡片：客户意图、用户情绪、匿名产品类别、故障域、工单类型、知识覆盖、匿名关联系统、知识分类。
2. 默认范围是全部会话。可切换常规会话、无效会话、直接转人工、范围待确认。按钮数量是该项目的完整范围数量。
3. 卡片显示已标注条数、覆盖率；每个标签显示会话数和占比。点击任意标签联动下方列表；跨字段可组合筛选，同字段单选，再次点击可取消。
4. 默认展示数量最多的前三项；点击“展开其余”查看全部，不合并或丢弃低频分类。“未标注”也可点击，定位缺少该字段的对话。
5. “查看匹配对话”跳到下方列表；打开完整对话后，返回链接保留范围、标签、搜索和页码。
6. 删除单个筛选标签或清空标签；空结果页可清空全部筛选。“刷新统计”读取最新已导入标签。分类区可收起，不影响列表筛选。

## 界面更新（2026-10-20）

- 面板标题为“会话数据画像”，统一主色、轻量图标与字号层级；情绪风险和知识缺口保留语义色。支持已有浅色、深色及自定义主色设置。
- 卡片按容器实际宽度自动切换列数，不在窄卡片中强塞四列。取消卡片底部的自动拉伸留白；默认三项，更多标签可展开。
- 数量采用等宽数字且禁止换行，计数列宽按该字段最长数字分配；长标签省略显示，悬停或无障碍名称可查看完整信息。
- 数量和占比分层对齐，同一卡片的条形轨道等宽，长度直接来自原始占比，不能因为数字位数不同改变比例尺。
- 加载时显示无数字骨架；读取失败隐藏旧统计并提供重试，零结果显示清晰空状态。筛选联动、缺失标签钻取和返回上下文保持不变。

## 统计规则

- 原始来源：已导入人工标注的 `labelSummary`，由有效 final 提交汇总。草稿及 cancelled 标注不计入，不新增模型推断或写回原标签。
- 统计单位是唯一完整会话，不是消息数、标注份数或当前页行数。同一会话重复出现同一标签只计一次。
- 当前分母等于搜索、范围、资料状态和标签组合筛选后的全部会话数；卡片与列表在同一个数据库读取事务中取得，分页不改变统计。
- 标签占比 = 含该标签的去重会话数 / 当前分母。条形长度直接对应这个比例，不按该卡片最大项另行归一化。
- 覆盖率 = 当前范围中具有该字段非空标签的会话数 / 当前分母。未标注 = 当前分母 − 已标注。不把缺失当作“其他”或自动补齐。
- 多值和分歧保留并提示。同一会话可同时计入多个标签，因此同字段标签占比之和可能超过百分之百。空范围显示无数据，覆盖率显示横线而非成功率。
- 范围分组互斥：明确无效优先；其次是明确直接转人工；常规要求两个范围字段均明确为否；其余是范围待确认。不会仅凭“没看到是”就当作常规，也不把这些标记当作实际接通人工或真实解决状态。
- 产品和系统保留脱敏类别，用匿名短标识方便阅读；悬停可查看完整匿名值，不恢复原组织或系统名称。

## 本机接口

GET `/api/support/sessions?dataset=PROJECT_ID&facets=1&page=1`

沿用原列表接口；无 `facets=1` 时保持旧返回结构。带统计必须指定已注册项目。页面动态获取结果，没有硬编码客户数据、截图数字或百分比。

参数：`scope=all|regular|invalid|handoff|unclassified`；`labels` 是 URL 编码的 JSON 对象，例如 `{"emotion":"不满（安抚话术）","knowledge_category":null}`；null 表示未标注。旧 `intent` 参数仍支持，但若与 labels 中的意图矛盾则拒绝。`q`、`status`、`page` 继续可用。

字段只允许八个分类字段，值使用 SQL 参数绑定；不接受自由 SQL / JSON 路径。返回 `facets` 内含 `projectTotal`、当前 `total`、`scopes`、`dimensions`。每维包含已标注 / 缺失 / 覆盖率 / 多值 / 分歧数及各标签计数。

本功能不调用外部模型，不向第三方制图服务发送客户数据，不改动会话或来源标注。只可能刷新原有派生索引。仍需按原隐私策略审核对外截图和导出资料。
