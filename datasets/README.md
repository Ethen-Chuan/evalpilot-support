# 数据不随源码发布

此目录的 manifest.json 初始为空。仓库没有附带任何客户对话、图片、标注、训练集、模型缓存或历史评测分数，也不重新分发第三方公开语料。

真实图文案例可在「模型对比 → 图文与转人工拦截」中，经本机扫描与人工确认后添加。文本语料导入步骤见 docs/CORPUS_IMPORT.md。

需要公开英文参考数据时，先自行确认授权与当前发布许可，再使用 scripts/prepare_public_data.py 处理本地原文件；产生的数据和第三方许可副本只保存在本机，不提交到源码仓库。该脚本不会下载文件。

Bitext、BANKING77 的名称仅作功能来源说明，不代表与本项目存在合作或背书。使用者负责独立核验数据来源、许可、脱敏及用途。
