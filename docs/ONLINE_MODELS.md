# 真实在线模型接入

更新：2026-10-20。接入功能已实现；未使用用户密钥进行供应商实测，不声称任何模型最好。

## 最短操作路径

任何页面右上角「连接模型」均可打开专用密码弹窗；`#models?connect=1` 可直接打开一次，关闭后不会被刷新轮询再次弹出。不要把 Key 放在网址或聊天里。保存和测试分开确认，测试通过后可点击「去选择模型和案例」。连接只用于已接通的评测功能，不代表生产发布、真实退款、派单或人工转接可用。

模型对比 → 添加模型 → 选择服务商并输入 Key → 授权读取账号列表或填写模型 ID → 保存内存配置 → 单独授权连接测试 → 完成并选用。

重复一次，在 A / B 中选择两个模型，选同一个案例，核对外发范围并确认费用后开始。可以是不同厂商或同厂商不同模型 ID，无需切换比较类型。可选统一裁判；实际答复、操作建议、沙箱结果、Trace 和 Token 记录来自运行，不预置成绩。

显示名称、归档系列和同服务裁判 ID 折叠在可选设置中。默认显示名为模型 ID。模型身份保存后锁定；新模型建新连接，替换 Key 不覆盖历史模型身份。

本地基线默认隐藏且不预选，需明确勾选后选择；新建普通评测同样不自动预选。历史重跑保留用户原来的模型选择。分类器与安全模板不是在线大语言模型。

- 所有列表只来自用户授权后的官方请求，不是硬编码“最新模型”。只保留合法模型 ID，不回传上游原始对象、错误正文或密钥。列表有分页/超限时明确提示仅部分结果，可手填其他 ID。
- 名录中可能有嵌入、语音、图片生成或当前适配器不支持的模型。列表可见不代表 Chat / JSON / 图像兼容、额度足够或已通过实测。
- OpenAI 使用 Chat Completions，不自动切换 Responses；仅支持其他协议的模型需另行适配。Claude 使用原生 Messages；其余使用各自官方的 OpenAI 兼容聊天接口。
- 百炼使用北京地域原域名，官方文档说明原域名仍可用。Key 必须属于北京；本适配器关闭可选深度思考并使用非流式 JSON。不支持这种调用方式的模型会明确失败，不换用另一个模型。专属工作区域名、其他地域需按文档另行适配。
- GLM 使用通用开放平台地址，不使用 Coding Plan 专用地址。其图像请求不发送仅文本支持的 response_format，而以提示要求 JSON 并严格校验返回。其他服务的订阅、代理、网关 Key 也不能假定与通用 API 通用。
- 文字测试检查候选及不同裁判模型的完整 JSON；图像测试必须读对本机生成的随机码。仅文字成功不视为视觉成功。测试不包含真实客户内容，最多两次调用，可能收费。
- 运行上限每次输出4096 token、不自动重试；输出截断、格式不合格、权限不足、网络或脱敏门禁失败都保留失败状态，不产生假成绩、不静默降级到本地模型。真实生产派单、转接没有接入，动作仍是沙箱结果。

## 安全与接口

- `GET /api/support/lab/services`：固定服务目录，不需要 Key。
- `POST /api/support/lab/connections/models`：`provider`、`apiKey`、`confirmed:true`。仅模型目录 GET；不保存 Key、不创建模型记录、不写 Trace、不发推理或客户数据。最多读取1MB、返回1000个合法 ID，默认只请求一页。
- `POST /api/support/lab/connections`：保存连接元数据与内存密钥。凭证不写 SQLite、浏览器存储、URL、导出或日志；保存/关闭后清空密码输入框。
- `POST /api/support/lab/connections/test`、`test-vision`：需独立确认。测试成功才可参与相应评测；文字复测失败会撤销旧的通过状态。
- 客户案例运行需另行授权，显示服务地址和最多调用次数。变更模型、裁判、案例或数量后撤销勾选。外发正文和返回仍经本地隐私扫描。
- 服务端仅访问白名单 HTTPS 地址，不跟随重定向；发现和调用出错都不回显原始上游正文。读取列表不会自动登记连接，更不会证明模型推理成功。
- 模型服务是本机单用户开发平台，尚无多人身份权限体系；不要直接暴露公网。

## 2026-10-22 接入窗口补充

- 连接窗口增加 DeepSeek Flash 快捷填写，模型 ID 使用 `deepseek-flash`。填写名称不代表图像能力已通过，仍需用户单独授权图片探针测试。
- 源码增加 DeepSeek-VL2 私有服务适配；它连接用户已有的部署，不会下载权重或在本机安装模型。服务地址只允许 `http://127.0.0.1:1024–65535/v1` 或 IPv6 回环地址，远端私有部署需先建立用户管理的隧道。仅本机服务允许不填 Key。
- VL2 图像使用内联数据，不允许任意远程图片或文件地址。模型清单来自实际部署；输出上限1024 token，不强制服务端 `response_format`，返回仍需通过结构校验。现有云服务 HTTPS 白名单不放宽。
- 这不是工具调用或 DSH Agent 循环实现。是否可用，以该连接在当前适配器中的实际文字、图片测试为准；不根据品牌名推断能力。
- 本次保留正在使用的后端进程，避免清空内存中的用户密钥。前端已更新；如果运行中的后端目录未包含 VL2，入口会明确禁用。启用新后端适配需要安排重启并重新输入密钥，未进行真实 VL2 推理或私有部署验证。
- 新增接口测试使用隔离本机响应，不产生供应商付费请求。不得把这些测试当作模型效果评测。
