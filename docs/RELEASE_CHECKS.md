所有拟发布文件逐一使用本机security-redaction-check扫描。扫描器不识别的cjs文件另建逐字节相同的txt副本并复扫，确认字节一致。没有把无法扫描的内容当作通过。

人工复核如下告警：

- backend/support_api.py与src/SupportApp.tsx的保密字样属于禁止输入受限内容的安全提示，不是业务资料。
- scripts/prepare_public_data.py命中拒绝受限内容的正则表达式，保留检测逻辑。
- 模型与图表模块的比例告警对应计算公式、训练档位、界面取值和统计口径，不是导出的私有成绩。
- 24张公开图片逐张视觉检查并核验原审核指纹；只有板卡物体及公开产品丝印，未见客户身份、人脸、工牌、二维码或地址，文件元数据为空。保留上游署名、来源与许可，不改动图像哈希放行逻辑。普通用户图片仍单独扫描，失败关闭。

自动扫描与人工复核均不能保证绝对安全。后续导入和外发仍需重新检查；公开仓库不能作为客户材料的备份位置。
