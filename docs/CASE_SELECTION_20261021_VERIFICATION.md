# 手动选择与随机抽取验收

日期：2026-10-21。范围：「运行评测 → 新建评测 / 重跑本批案例」的第二步。

## 使用方式

- 「随机抽取」填写数量后立即显示抽样清单，可点「换一批」。批内无重复，批间可以重合；选满可用池时禁用换一批。案例多于 10 个时分页查看。
- 「手动选择」搜索问题、编号或意图并勾选，支持选中本页、仅看已选、清空已选。翻页和搜索不清除已选案例。
- 显示实际案例数、模型数和待评测输出数。所有候选模型收到相同案例集合；裁判调用量单独在外发授权中说明。
- 重跑严格限定原批次案例；原清单缺失或有案例不可用时阻止提交，不回退为全项目抽样。

## 实现与边界

- 抽样使用无放回部分 Fisher–Yates 洗牌，保存在弹窗状态中。不使用固定种子、排序前 N 个或预置清单。
- 新建和重跑均向现有接口提交明确的 `caseIds`；服务端验证独立测试集范围并冻结案例编号与指纹。数量输入无效时不偷偷纠正或提交旧样本。
- 模型列表刷新、修改模型或裁判不会重抽案例。改变选例方式、数量、清单、模型或裁判会清除外发确认。
- 提交期间锁定操作，拒绝重复提交；读取失败可重试，过期请求不能覆盖新项目的案例池。
- 此次不修改其他入口的抽样协议；旧客户端只传 `count` 的兼容行为保持不变。
- 不涉及训练、自动运行模型或线上业务效果；预览、搜索、换一批均无模型调用。
